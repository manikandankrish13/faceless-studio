How to create the token (2 minutes)
  • Open github.com/settings/personal-access-tokens/new
  • Token name: Faceless Studio. Expiration: 1 year.
  • Repository access: Only select repositories → youtube-ideas
  • Repository permissions: Actions: Read and write, Contents: Read-only, Secrets: Read-only (optional, shows the checklist)
  • Generate, copy, paste above. It stays in this browser only.
