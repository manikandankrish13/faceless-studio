How to create the token (2 min)
  1. Open github.com/settings/personal-access-tokens/new
  2. Name Faceless Studio, expiration 1 year
  3. Repository access: Only select repositories → youtube-ideas
  4. Repository permissions: Actions: Read and write · Contents: Read-only · Secrets: Read and write
  5. Generate → copy → paste above → Connect

How to get it (5 min, once)
  1. Create a Google Cloud project named "Faceless".
  2. Enable the YouTube Data API v3.
  3. OAuth consent screen: External, add your own Gmail as a test user.
  4. Create an OAuth client, type Desktop app, then Download JSON.
  5. Open the file, select all, copy, paste below.

Google ends on a page saying it can't connect to localhost. That is expected: copy the whole address from the address bar.
