Setup checklist

Everything is saved securely as repository secrets. Nothing sensitive stays in this page except your GitHub token, which is kept in this browser only.

1
Connect GitHub
Lets this app start renders and save your keys.
How to create the token (2 min)
  1. Open github.com/settings/personal-access-tokens/new
  2. Name Faceless Studio, expiration 1 year
  3. Repository access: Only select repositories → youtube-ideas
  4. Repository permissions: Actions: Read and write · Contents: Read-only · Secrets: Read and write
  5. Generate → copy → paste above
2
Claude API key not set
Writes the scripts and ideas. A few cents per video. Get it at console.anthropic.com.
3
Stock footage not set
Free keys give real moving footage instead of photos. Pexels key · Pixabay key (optional)
4
Connect YouTube not connected
Needed only for uploading. Three short parts.
How to get it (5 min, once)
  1. Open console.cloud.google.com/projectcreate, name it “Faceless”, Create.
  2. Enable the YouTube Data API v3.
  3. OAuth consent: External, add your own Gmail as a test user.
  4. Create OAuth client: type Desktop app. Tap Download JSON.
  5. Open the downloaded file, select all, copy, paste below.
Google will end on a page that says it can’t connect to localhost. That is expected. Copy the full address from the address bar.
5
YouTube research key optional
Lets the idea engine study top fact channels before YouTube is connected. In the same Google project: Credentials → Create credentials → API key.
