How to get it (5 min, once)

Before you start: open these links in Safari itself, not from the home-screen icon. In Safari tap the aA button in the address bar and choose Request Desktop Website: Google's console only works properly that way. Each link below first asks which Google account to use; pick the one that owns the channel.

  1. Create a project: name it Faceless, tap Create, wait for the notification, then tap Select project.
  2. Enable YouTube Data API v3: make sure "Faceless" shows at the top, tap Enable.
  3. Google Auth Platform: tap Get started. App name Faceless, support email = your Gmail, Audience External, contact email = your Gmail, agree, Create.
  4. Still there, open Audience → Test users → Add users → your Gmail → Save.
  5. Create OAuth client: Application type Desktop app, name Faceless Studio, Create, then Download JSON.
  6. Open the downloaded file (Files app → Downloads), tap and hold the text → Select All → Copy, paste below.

If you have access to any computer for 10 minutes, this step is much easier there. Everything else in this app is phone-friendly.

Google ends on a page that says it can't connect to localhost. That is expected: copy the whole address from the address bar.
